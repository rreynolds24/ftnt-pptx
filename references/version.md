# Version 2.0.0

Release date: September 25, 2026.

Baseline: the complete supplied `fortinet-branding-updated/skill.zip`, SHA-256
`45f1493195226035e8c3bd592b5b639336b580049a9983e4c03303159e62e6af`.
The baseline package did not carry a semantic version. Its original bytes are retained separately and were not overwritten.

This release adds a source-traceable learning register, offline audit/plan/apply utilities, explicit picture/shape/table styling, verified asset lookup, source-specific crop reproduction, review-only local library import, optional local rendering checks, and a data-driven architecture builder. It retains the baseline editorial guidance, visual guidance, logo kit subset, source text, reference pages, and formal palette.

Scope of promotion: the new packaged Skill and standalone toolkit produced in this conversation, under the user's explicit approval to promote these learnings and include offline tooling. This release does not assert that a ChatGPT installed Skill, a Codex installation on another machine, or a GitHub branch has been updated. No remote write, new credential, repository permission, or background update process is introduced.

Dependency profiles:
- Core inspection/restyling and catalog query: Python 3.10+ standard library.
- Optional PDF crop and render checks: local PyMuPDF; LibreOffice for PPTX-to-PDF.
- Optional new-slide builder: Node.js 18+ and PptxGenJS 4.0.0, separately installed before offline use.
- Inter: installed locally when rendering; no font files bundled.
