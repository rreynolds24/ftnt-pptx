# Fortinet formal brand system

Read `source-precedence.md` first when sources differ.

## Typography

- Formal document/web/print font family: **Inter**.
- Apply Inter to body text, headings, tables, captions, headers, footers, callouts, and labels unless an official artifact-specific rule supersedes it.
- Primary weights from the supplied brand guide: Light, Regular, Semi Bold, Bold.
- Recommended document sizing baseline:
  - Cover title: 24-30 pt, Bold
  - Section heading: 14-18 pt, Bold
  - Subheading: 11-13 pt, Semi Bold/Bold
  - Body: 9.5-11 pt, Regular
  - Table body: 8.5-10 pt, Regular
  - Metadata/footer: 7.5-9 pt, Regular/Medium
- For PowerPoint, the October 2024 guide names Arial as the presentation exception. If the user explicitly requests Inter for a presentation, use Inter as instructed.
- Do not bundle, expose, or return font files.

## Usage hierarchy

### Primary identity

- Fortinet Red: primary brand accent, protection/stop motif, section markers, primary table headers, selective emphasis.
- Black / white: principal text and background contrast.
- Light/neutral greys and Silver: dividers, secondary text, table structure, metadata, quiet backgrounds.

### Semantic secondary accents

Use semantic mapping only when it improves comprehension; do not force this mapping over an official template or source diagram.

- Blue: engineering, technical findings, platform/support workstreams.
- Purple: future state, strategy, transformation, roadmap.
- Connectivity Yellow: connectivity highlights, pending actions, attention, or controlled caution. Use dark text on yellow.
- Teal: architecture, connectivity, network paths, integration.
- Green: confirmed, resolved, approved, healthy, positive state.
- OT Grey: operational technology or subdued infrastructure contexts where the newer palette calls for it.

## Document layout baseline

### Cover

- White, light-grey, or dark-neutral background with Fortinet Red as the dominant accent.
- Prefer an official full-color logo treatment with adequate clear space and contrast.
- Use strong hierarchy, substantial whitespace, and only purposeful design components.
- Include title, subtitle, date/version, and audience/classification where useful.

### Body

- White/light background for sustained reading.
- Black primary body text.
- Red-led heading/marker system, with secondary colors used deliberately.
- Use approved design components and tints/shades only when they aid hierarchy or storytelling.

### Tables

- Primary header: Fortinet Red fill with white text.
- Secondary header: approved neutral or secondary color with sufficient contrast.
- Body rows: white or a restrained approved light tint where an official template calls for it.
- Borders: Silver/neutral grey, thin.
- Avoid arbitrary Office theme colors and rainbow formatting.

### Callouts

- Prefer a light/white panel with a narrow approved-color edge, top rule, or heading.
- Use saturated full-panel fills only when the official template demonstrates that treatment and readability remains high.

## Prohibited substitutions

- Do not use `EE3124` as Fortinet Red.
- Do not introduce unrelated Office theme colors when an approved Fortinet color exists.
- Do not invent gradients, neon palettes, or faux brand elements.
- Do not modify official logo artwork.
